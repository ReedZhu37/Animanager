# Animanager 0.4 工作区

本次交付以 Windows 桌面为验收平台，保留资产库、3D 预览、FBX 管线、批量任务与 Limbo Console。

## 调整布局

- 拖动面板顶部标签：放到其他面板中央组成标签组，放到边缘建立上下或左右分区。落点有高亮提示，Esc 取消拖拽。
- 拖动分隔线改变比例。标签右侧的 `⋮` 菜单提供隐藏、最大化、恢复和不依赖拖拽的移动操作。
- “面板”菜单重新显示隐藏面板。“工作区”提供浏览、预览、批处理、动画检查预设；可保存具名布局、恢复已存布局或恢复默认布局。
- 布局、面板顺序、缩放、控件密度和窗口位置保存在应用配置的 `workspace.json`，切换 Library 时继续使用同一套工作区。应用配置首次建立时，会读取启动库已有的布局。停靠操作会保留当前模型和动画位置。
- 配置损坏时回到默认布局并提示；窗口从不可用屏幕恢复时限制到当前可用区域。最后一个面板不能被隐藏。

## 骨骼与轨迹面板

通过“面板 → 骨骼”或预览左上齿轮的“骨骼与轨迹…”打开。齿轮还提供预览角色选择和显示设置，不再占用视口上方的固定区域。使用“工作区 → 动画检查”可以将骨骼树和预览并排显示；骨骼面板支持现有的拖动停靠、标签合并、隐藏、最大化和布局保存。已有布局保留原来的排列，新面板可从菜单打开。

1. 在资产列表选择模型或动画，骨骼树按骨架分组并显示真实父子关系。
2. 输入名称搜索，忽略大小写，保留匹配骨骼的祖先路径。支持中文名称；同名骨骼通过所属骨架区分。
3. 单击骨骼替换选择，Ctrl 点击增减选择，Shift 点击选择连续范围；所有选中骨骼在预览中高亮。面板显示总数与主选骨骼，双击或点击“聚焦”将相机中心移到主选骨骼。“显示骨架”和“穿透显示”分别控制全部骨架线和遮挡行为。
4. 开启“显示选中骨骼轨迹”，查看全部选中骨骼在当前完整片段中的路径；选中后也可直接使用视口左上“轨迹”开关。面板显示计算状态、采样点总数和起终点图例，预览可继续播放。骨骼与轨迹文字为固定逻辑字号的二维标注，相机缩放不会放大文字或导致纹理模糊。
5. “参考空间”默认世界空间；选择“相对 · 骨骼名 [编号]”可抵消指定骨骼的位移、旋转与缩放。30 / 60 次每秒为轨迹采样率，不代表源动画帧率。

面板和 Console 共用选择、轨迹、参考空间与显示状态。搜索不会清除任何选择或轨迹；面板提示被筛选隐藏的选中数量。Ctrl 点击搜索结果可以继续添加骨骼，普通单击则替换全部选择（含被筛选隐藏的项）。可用“定位选中”清除搜索并展开到全部选中骨骼。切换资产清空旧选择、搜索、固定轨迹和 Root Motion 来源；切换片段保留配置并重新采样。静态骨架仍可搜索和多选，动画相关开关会禁用并说明原因。

小窗口或高 DPI 下，面板随工作区切换为标签，内容可纵向滚动；骨骼树本身也支持滚动。播放只刷新选中骨骼的信息，不重建树或改变折叠状态。轨迹算法、Console 命令及当前兼容边界见 [骨骼检查说明](CONSOLE.md#骨骼树多选与固定轨迹)。

“固定选中轨迹”将全部选中骨骼加入固定列表，记录当时的参考空间和采样率；相同配置重复固定不生成重复项。每行显示骨骼名称 / 编号、pin ID、参考空间和采样率，复选框控制显隐，“移除”删除该项，“清空固定”删除所有固定项。列表可独立滚动。切换或清除选择后，固定轨迹继续显示。

固定项和选中轨迹各有独立开关：隐藏固定项时，若同一配置仍由“显示选中骨骼轨迹”开启，列表会提示“选中轨迹仍显示”。关闭选中轨迹开关也不会隐藏其他固定项。

Root Motion 区域先选择根骨骼，再打开“显示 Root Motion”。菜单只包含无父骨骼的根关节，附带骨架 / 骨骼编号以区分同名根；不自动猜测来源。预览显示世界空间根运动路径与朝向，面板显示采样数和当前位移，支持播放 / 拖动时间轴时更新。Root Motion 独立于选中轨迹和固定列表，其位移以片段首帧为基准，不提取或改变角色播放，也不跨循环累计。

验证入口：`Test.ps1 -Suite BoneUI`。测试覆盖输入事件选择、轨迹开关、下拉菜单、Console 同步、旧布局恢复、停靠、空状态、多骨架同名、中文筛选、720×400 和 200% 缩放。构建后以 `--bone-ui-test` 启动，报告写入 `TestResults/bone-ui-<时间>/`；非 headless 运行同时输出实际界面截图。

`Test.ps1 -Suite MultiBoneUI` / `--multi-bone-ui-test` 专项验证 Ctrl / Shift 多选、搜索保留选择、固定列表显隐 / 移除、Root Motion 来源与显示、Console 同步、停靠、同名根骨骼、片段 / 资产切换和嵌套滚动。报告位于 `TestResults/multi-bone-ui-<时间>/`，图形模式另外保存桌面与 200% 缩放截图。

## 小窗口与 DPI

布局按逻辑空间判断。空间不足以容纳分区时，自动合并为可切换标签；扩大窗口后恢复原分区，不覆盖桌面布局。面板内部可滚动，工具栏自动换行。默认布局不足约 1000 逻辑像素宽时会进入此模式，更复杂的分区会按实际最小尺寸提前切换。

“显示 → 跟随系统”在 Windows 上读取当前原生窗口的 DPI；手动支持 100%、125%、150%、175%、200%，这是总缩放值，不与系统比例重复相乘。系统模式检测 DPI 变化，子窗口使用相同比例。系统字体使用 MSDF 渲染以避免动态缩放时小字号字形缓存异常；保留中文字体回退。宽松控件间距可单独开启。

最小窗口按 720×400 逻辑单位换算，并以当前屏幕可用区域为上限；小屏无法容纳此下限时仍优先留在屏幕内。已经验证 720×400 逻辑单位的小窗口面板可达性，以及 125%–200% 的布局边界。真实 Windows 窗口验证系统 150% 与手动 200%。不同 DPI 的实体双显示器来回拖动、触摸设备、macOS / Linux 尚未实机验收，不计为已验证支持。

## 一致的控件与输入

统一按钮、输入框、选项、列表、面板标题、焦点边框、禁用态、文字和间距；控件由 Container 与尺寸策略布局。长资产名截断并提供完整悬停提示；错误和说明在可滚动弹窗内展示。

| 操作 | 方法 |
| --- | --- |
| 搜索 | Ctrl+F；输入框内键入不触发预览快捷键 |
| 切换面板焦点 | F6；具体控件继续用 Tab 导航 |
| 播放 / 暂停 | 预览具有焦点或鼠标位于预览时按空格 |
| 相机 | 中键/右键旋转，Shift+中键或 Shift+左键平移，滚轮缩放；按钮也可缩放、适配 |
| Console | F12 或反引号；关闭后恢复原输入焦点 |

导入和 FBX / GLB / RES 导出共用顺序任务队列。任务面板显示状态、完成数、报告路径、导出配置和失败信息，支持取消、重试失败项。关闭应用时如仍有任务，会提供“继续运行”或“取消任务并退出”，已完成的输出保留。

## 导出选项与资产浏览

导出面板支持当前资产、跨页多选和当前筛选的全部结果。选择是否包含 Mesh、已有动画片段，以及可选的起止时间和输出采样帧率。RES 保存动画库，因此不包含 Mesh。批量指定片段名称时，每项分别校验；没有对应片段或时间范围无效的资产会报告失败，其他资产继续导出。原始资产和预览状态不随导出改变。

资产列表自动生成可复用缩略图，并提供骨架、时长和源帧率筛选。属性来自解析结果，源帧率未知时明确显示未知；预览速度和导出采样帧率不会改写源属性。筛选对整个候选范围生效，然后分页；名称 / 标签搜索、分类与集合可同时使用。切库取消旧库的浏览结果并保持工作区布局。

缩略图在资产进入列表可见区域时按需生成，取首个动画片段约 35% 处的姿态；使用独立灰模场景，不改变正在播放的预览。没有 Mesh 的骨架可显示姿态线框。属性解析覆盖 GLB / glTF、独立 `.motion` 和二进制 FBX 7+；ASCII / 更早 FBX 或未声明的属性保持未知，不影响既有导入预览。

缩略图和解析属性保存在库内独立的 `preview-cache` 目录，可在 **Library → 缓存清理** 中预览并清理，后续浏览重新生成。它们不属于动画原始数据，也不是完整备份恢复的必要文件。

验证入口：`Test.ps1 -Suite P1`，包含 `ExportOptions` 和 `AssetBrowse` 两组。

## 当前边界

工作区使用单窗口。资产多选、集合及回收站的操作见 [管理素材库](../README.md#管理素材库)。浮动面板、跨窗口停靠、表格列配置和独立缩略图网格待后续迭代；本轮缩略图显示在资产列表内。批量导出可通过导出面板或 Console 完成。

主要实现：`UI/Workspace` 负责布局模型、停靠和 DPI；`UI/Controls/AppControls.cs` 与 `UI/StudioTheme.cs` 提供统一控件；`MainShell.Workspace.cs` 连接应用功能。验证入口：`Test.ps1 -Suite Interface`。
