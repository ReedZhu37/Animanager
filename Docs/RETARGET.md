# UE4 / UE5 Retarget

2026-11-17。内置 UE4 男体/女体（68 骨骼）与 UE5 Manny/Quinn（161 骨骼），支持通过 Ready-v1 检查的人体源动画与自定义角色。规则与视口操作见 [资产准入规则](ASSET_READINESS.md)。通过跨动画库共享的角色库选择目标，在应用内预览并导出 FBX、GLB 或 Godot AnimationLibrary。动画和源文件保持不变，不生成派生动画资产条目。

## 使用

预览区上方的 **预览角色** 包含原始角色、UE4 男体/女体、UE5 Manny/Quinn 和已导入的 Ready 角色。选择角色后自动重定向当前动画；更换动画或切换动画库时保留角色，重新启动后也恢复选择。正在播放时更换角色或动画可继续播放。无法处理的源动画会明确提示并显示原始角色，同时关闭该次重定向导出。

工具栏或预览区的 **角色库** 可查看角色缩略图、静态模型、骨骼数和兼容性。点击 **导入角色…** 或向角色库窗口拖入 FBX / GLB / glTF，通过检查后自动用于动画预览；也可选中后点击 **用于动画预览**。自定义角色可重命名、移出；移出只隐藏条目，保留模型供已有配置和导出任务使用，重新导入可恢复。非兼容模型可静态查看，但不能选择为动画目标；任意骨名映射编辑器尚未实现。

应用将导入的角色存为包含当前可读取材质的独立参考姿势 GLB，移除输入文件的动画轨道。缺失的外部纹理仍需由素材提供方补齐。MechanicGirl 已在本机角色库导入，115 骨骼、17 网格，使用 UE5 层级映射；用户模型不打包进应用内置资产。

默认角色库位于 `user://Characters`（Windows 为 `%APPDATA%/Godot/app_userdata/Animanager/Characters`），独立于当前动画库。可用 `--characters-dir=<目录>` 指定另一角色库；库内条目使用相对模型定位，模型按内容哈希去重，角色选择单独持久化。配置与排队导出保存角色 ID、模型路径、内容哈希和映射族，执行时验证模型哈希。移动角色库后需重新选择目标并保存旧配置；动画库的备份不包含这个共享角色库，应同时备份 Characters 目录。

普通 GLB / FBX 预览使用最多三个结果的会话缓存，大型轨道和 `.motion` 依赖动画不进入该缓存。快速更换选择时取消旧计算，旧结果不能覆盖新角色。

1. 预览一个标准人体动画，点击工具栏 **Retarget**。
2. 从角色库的兼容目标中选择角色，按需设置原地、根位移倍率、骨盆高度和局部旋转补偿。旋转单位为度，高度单位为米。原地固定裁剪起点的水平位移，保留垂直位移和转向。
3. 点击 **应用并预览**。计算完成后可播放、逐帧检查、查看骨骼和轨迹，并切换源动画、目标角色或并排对比。计算过程可取消；调整参数后需要再次应用。
4. 输入名称，点击 **保存预设与当前资产配置**。重新选择该资产会恢复配置；预设也可用于同一源骨架的其他动作。
5. 前往导出，选择 FBX、输出目录、片段、裁剪区间和采样帧率。勾选 **导出时使用以下重定向配置** 时，当前参数随批量任务保存，失败重试沿用原快照。FBX 转换需要 Blender。

**恢复源动画** 同时关闭本次重定向导出；保存的预设和资产关联仍保留。预览的并排位置不进入导出文件。导出使用当前控件参数，修改后可先重新预览确认。

默认采用已知源帧率，未知来源采用 60 FPS。包含独立武器的 `.motion` 默认使用 **600 FPS**，以减少快速转刀的帧间误差；显式指定的 1–600 FPS 优先。降低帧率可能增大高速旋转的插值误差。每个片段最多 4,000,000 个骨骼姿态采样，超限时需要裁剪或降低帧率。

## 求解和数据

- `RigCatalog` 按骨名、层级和模型空间参考位置识别已知骨架，允许 FBX 骨轴方向差异。目标网格、权重、原 Skin 绑定及参考姿势保持不变，未加权的 UE5 标准骨骼由固定 rig 定义补齐。
- `RetargetSolver` 在统一模型空间计算源参考姿势到当前姿势的旋转增量，再求目标的局部姿势。脊柱和颈链按参考骨链的累计长度分配旋转；twist 辅助骨单独处理。跨骨架保持目标骨段长度，骨盆位移按腿部参考高度比例调整。旋转补偿作用于目标骨骼局部空间并传递给子骨骼。
- 预览和导出都调用 `RetargetBaker`。预览先生成缓存轨道，再正常实时播放。FBX 由同一结果生成临时 GLB，再经 Blender 转换；Blender 不做第二次重定向。裁剪只执行一次，保留精确末端采样。
- `.motion` 的独立武器保留相对右手的原始运动，经参考手部坐标系校正后烘焙为独立世界空间轨道。握持展示偏移随道具保留，接触记录不参与 IK。诊断刀仍是应用参考几何，不是素材包原武器模型。
- 官方 `UE5_Manny_Idle.fbx` 的参考骨段长度与 Manny 网格基准存在差异，作为明确的已知源变体识别；其他比例和常见人体命名进入自动映射及 Ready-v1 检查。

库内持久数据：

```text
retarget/<preset-id>.json       # 命名配置
retarget/assets/<asset-id>.json # 当前资产关联配置
jobs/                          # 含 Retarget 参数快照的既有任务记录
```

配置包含版本、源/目标 rig ID 与基准哈希、原地选项、位移倍率、高度、旋转补偿和独立武器开关。哈希覆盖算法版本标记、固定模型和 rig 数据；基准变化时拒绝旧快照，避免静默改变结果。库检查会验证配置，完整备份与恢复包含这些文件。

`.res` 包含目标轨道，需要匹配 `Retargeted/Character` 场景下的骨架路径及独立道具节点；可导出同配置 GLB 作为接收场景。它不是可直接绑定任意角色的通用动画文件。

## Console

### 自定义角色试验

显式 `RetargetBaker.BakeToTargetAsync` 入口用于通过 Ready-v1 人体映射检查的自定义目标模型。角色库通过带哈希的 `CharacterReference` 接入同一求解器，目标沿用自身比例、参考骨架、蒙皮及额外骨骼。界面的目标下拉框已接入角色库；常见人体别名可自动映射；手动 BoneMap 编辑器尚未实现。

MechanicGirl 的试验使用 `SK_MechanicGirl_01.fbx`，生成走路、跑步、蹲走、待机四个动作及各自 FBX，并合并为可在预览下拉框切换的 GLB。保持 115 根骨骼、17 个网格；四个片段的顶点/权重/绑定/参考骨架哈希保持一致，未映射附加骨骼保留局部参考姿势并随父骨运动。全部使用原地、60 FPS，无脚底接触 IK。实测 FBX 回读误差小于 0.011 mm / 0.1°。

此轮还修复了应用首次进入 SceneTree 时使用尚未更新的全局变换，导致首段动画整体朝向错误的问题。采样改为直接累计模型内节点局部变换；独立武器直接读取已验证的手部相对轨道。修复后既有 75 项 Retarget 回归通过。

本地可用 `--retarget-demo=<request.json> --data-dir=<测试库父目录> --keep-open` 复现实验，配置格式为 `{"Target":"角色FBX路径","Family":"ue5-mannequin","Clips":[{"Name":"01_Walk","Source":"源动画路径"}]}`。入口创建独立测试库，输出每段 GLB/FBX、合并预览文件、截图和校验报告；`--keep-open` 保留预览窗口。

### 标准目标命令

```text
retarget inspect <asset-id> ue5-mannequin
retarget preview <asset-id> ue5-mannequin
retarget presets
retarget save <asset-id> "UE4 to Manny" {"TargetRig":"ue5-mannequin","InPlace":true}
export asset <asset-id> fbx "D:/Exports" {"Retarget":{"TargetRig":"ue5-mannequin"},"SampleFps":60}
```

已有 `export options_plan` 和 `batch export_with` 接收同样的 `Retarget` 字段。预设绑定源骨架；混合骨架批次中的不匹配项会单独失败，其他项继续。

## 边界与验证

本版不提供任意骨架编辑/BoneMap、接触或脚底锁定 IK、UE Post Process/纠正骨求解、完整 Root Motion 语义转换。无法匹配的辅助骨保留目标参考姿势并列出诊断信息。已标记的加法 GLB、非均匀缩放、镜像、奇异姿态及多人体 Skeleton 会拒绝；不支持蒙太奇、约束、曲线或事件的重定向。

运行 `Test.ps1 -Suite Retarget`。覆盖双向参考/动画姿势、链端旋转、目标骨长与 Skin、原地/裁剪、预设与备份恢复、取消清理、混合批次重试、界面应用/保存/恢复/排队导出，以及真实 Blender FBX 回读。安装本地样例库时还检查 Movement 走/跑/蹲/转向和 Nodachi 连招转刀。

`Test.ps1 -Suite Characters` 运行角色库集成测试，使用隔离的角色库和动画库，默认读取本机 MechanicGirl 样例，也可运行引擎时传 `--character-file=<FBX路径>`。覆盖去重、持久化、移出恢复、未蒙皮模型、三个角色实际动画、预览缓存、快速切换、跨库保留选择、FBX 与排队导出快照、模型篡改检测。GLB 归一化保持样例顶点位置、绑定变换和有向三角形集合，权重量化误差最大约 0.0000611。

本次验证通过 75 项 Retarget 专项、261 项既有原型/管线/批处理/界面/多骨骼/库管理/导出配置回归，以及 9 项独立 Windows 程序冒烟检查；已检查实际渲染的并排预览。独立打包同时补齐 CUE 导入器对共享存储代码的编译引用。

本机实测：真实人体 FBX 回读最大位置误差约 0.061 mm、角度误差小于 0.1°；高速武器在 600 FPS 的半帧位置相对原运动误差约 1.72 mm / 0.105°，FBX 与缓存轨道差异约 0.012 mm / 0.056°。这些是测试样例的结果，不是任意动作的误差保证。尚未在 Unreal 中重新导入验收。
