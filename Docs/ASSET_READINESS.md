# 人体资产 Ready-v1 与预览约定

2026-11-17。Ready 表示通过当前人体兼容检查，允许自动重定向；动作效果由预览评估。这个状态不等同于艺术验收，也不承诺任意命名、非人形角色或任意编码都可用。

## 状态和处理

| 状态 | 含义 | 应用行为 |
| --- | --- | --- |
| 未检查 | 尚未加载并检查资产 | 不提前声明兼容 |
| Ready | 人体映射、结构及对应数据检查通过 | 导入角色后自动选用；换动画后保留角色；可重定向导出 |
| 待修复 | 一项或多项硬性规则失败 | 保留入库文件；显示原因；不自动用作角色目标。自动重定向失败时保留上一预览，可主动选择原始角色检查 |

动画的检查结果显示在视口设置和属性面板；角色库在导入时记录检查结果，旧角色条目首次读取时按新规则复查。结果与错误说明分开，不能因为文件能加载就标记为 Ready。只有经过检查的资产有 Ready 状态，尚未加载的动画不会被当作已检查。

## 硬性规则

1. 一个可识别的人体 Skeleton，有唯一根部，父子层级有效。允许骨盆本身作为根部，不强制存在名为 `root` 的骨骼。
2. 必须能唯一映射 15 个部位：骨盆、至少一节脊柱、头、左右上臂/前臂/手、左右大腿/小腿/脚。手臂应属于躯干，腿应属于骨盆，各段顺序正确。允许中间插入辅助骨。
3. 参考变换有限、可逆、无镜像；当前求解器要求骨架均匀缩放。骨骼数量、身材比例和骨轴方向不要求与标准男体一致。
4. 角色必须有连接人体骨架的蒙皮。绑定骨骼存在，逆绑定矩阵有效；顶点与权重有限，权重非负、有有效骨骼索引，总和与 1 的差不超过 0.02。允许附加静态配件。
5. 动画至少有一个非 RESET 片段、正时长和有效骨骼关键帧。启用的骨骼轨道必须能解析到源骨架；检查关键帧时间、位置、旋转与缩放。不要求每根骨骼都有动画轨道；允许片段区间外用于边界插值的支撑关键帧。
6. 已标注为加法动画但缺少基准姿势的文件不通过普通重定向检查。多骨架、缺失映射、无效蒙皮也不会静默降级成 Ready。

## 映射与效果

内置 UE4 男体/女体（68 骨骼）、UE5 Manny/Quinn（161 骨骼）。女体使用本机 Epic 模板导出的真实资源；UE5 未加权辅助骨按固定定义补齐。UE4 女体来源及哈希见 `BuiltinAssets/Baselines/female-provenance.json`。

自动映射支持 UE 命名、Mixamo 常见命名，以及 Hips/Spine/Chest、LeftUpperArm 等常见人体别名。命名空间、大小写和常见分隔符可归一化。匹配不明确时返回缺失/冲突列表，不用空间距离猜测后冒充 Ready。暂未提供手动 BoneMap 编辑器；未知命名需在源工具中按规则命名后重新导入。

多余的头发、衣服、面部与辅助骨不直接导致失败；没有对应运动的骨骼保持局部参考姿势并随父骨移动。T/A 参考姿势差异、穿模、脚滑、手部偏差、扭转骨观感属于效果问题，可用现有旋转补偿、骨盆高度及根位移配置调整。接触 IK、自动蒙皮和非人形映射未包含在此版本中。

Ready-v1 是结构和数据准入，不是给每个导入动画提前生成四份成品。用户切换四个标准目标或自定义 Ready 角色时使用同一重定向流程按需烘焙。运行失败会显示原因并关闭本次重定向导出。原文件保持不变。

## 播放与视口

- 连续速率滑条：0.1–3×，步长 0.05；点击倍率数值恢复 1×。
- 当前帧 / 总帧：从 1 开始，按源 FPS 显示并包含末尾采样点。未知 FPS 使用 30；播放倍率不改变帧数。悬停可查看秒数和 FPS，重定向的高密度武器烘焙不改变源帧数。
- 左上齿轮打开独立视口设置：选择预览角色、角色库、粘土材质、地面网格、透视/正交、聚焦与骨骼面板。预览不再预留标题、状态与选角栏。
- 右上导航按钮：直接按住旋转、平移或缩放按钮并拖动，松手结束；不切换持久工具模式。
- 右上坐标轴：拖动旋转，点击正/负轴切换正交视图；坐标与 Godot 场景一致，Y 向上。
- 中键/右键旋转，Shift+中键或 Shift+左键平移，Ctrl+中键与滚轮缩放。
- 选中骨骼后，视口显示骨骼名和“轨迹”开关，与骨骼面板及 Console 同步。骨骼与轨迹文字绘制在窗口二维层，固定逻辑字号，避开工具按钮与相邻标签；不随相机远近缩放。
- 轨迹、骨骼连线采用固定屏幕线宽；起点、终点和当前点采用固定屏幕半径。相机缩放、透视／正交切换及视口尺寸变化不改变粗细，轨迹的空间位置仍随相机正常投影。保留穿透显示和正常深度遮挡。
- 切换动画先在不可见场景中加载、检查并完成重定向，再一次性替换显示。准备期间保留当前画面；取消、快速连选或失败不会显示中间原始骨架。
- 小键盘 1/3/7 为前/侧/顶视图，Ctrl 切换反向；5 切换透视/正交；F 或小键盘句点聚焦。窄视口的多片段列表收为下拉框。

导航行为参考 [Blender 3D Viewport Navigation](https://docs.blender.org/manual/en/latest/editors/3dview/navigate/introduction.html)，不是完整复制 Blender 编辑器。

## 验证入口

`Test.ps1 -Suite Feedback`：四种标准目标、GLB 回读、Mixamo 别名、关键映射缺失、错误层级、骨盆作为根骨骼、普通导入自动选角、速率、帧数与末帧、视口导航。图形模式使用 `--feedback-test`，额外检查坐标轴实际 GUI 拖动并生成桌面/200% 小窗口截图。测试数据写入隔离目录，不修改用户库。

`Test.ps1 -Suite SecondFeedback`：资产切换逐帧观察、取消与过期请求、失败保留画面、二维文字、选中轨迹开关同步、导航按钮鼠标拖动、独立视口设置与选角、200% 小窗口布局。图形模式使用 `--second-feedback-test`，另存近/远视图及设置页截图。验收记录见 [第二轮反馈](Validation/SECOND_FEEDBACK.md)。
