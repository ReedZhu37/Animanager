# Animanager 0.4 Beta · Windows x64

这是供内部试用的便携测试版。完整解压后运行 `Animanager.exe`，请保留同目录的 PCK、运行库、`BuiltinAssets` 和 `Importers`。无需安装 Godot 或 .NET SDK。默认素材库位于 `%APPDATA%\Godot\app_userdata\Animanager\Library`，可在应用的 Library 菜单登记或切换其他库。

## 可以试用

- 导入和浏览 FBX、GLB、glTF，以及已支持的 UE `.uasset` / ZIP 动画；搜索、筛选、标记、收藏和集合。
- 使用多个本地库，进行资产回收、恢复、完整性检查与备份。
- 播放、观察骨骼与轨迹；对已支持的 UE4 / UE5 人体骨架预览或导出重定向结果。
- 导出 GLB、Godot AnimationLibrary 和 FBX；FBX 导出需要另行安装 Blender 并在应用中配置其路径。

## 试用边界

- 这不是正式发布版：尚无安装器、代码签名、自动更新，也尚未在干净的 Windows 虚拟机上验收。
- `.uasset` 的支持取决于 UE 版本、动画编码和骨架；不支持直接导入 RAR、Montage、通知、事件或完整动画蓝图。受支持范围详见 `Docs/CUE4PARSE_IMPORT.md`。
- 目前仅支持已知 UE4 / UE5 人体层级和指定兼容目标，不支持任意骨名映射、脚底锁定 / 接触 IK、完整 UE 重定向语义或任意动画加工。
- 自定义 FBX 的外部纹理若缺失或引用无法解析，模型仍可能导入，但材质可能不完整；请检查素材和贴图依赖。
- Lucy 的脚部修正是对本机 Lucy 修正版素材库的处理，并非通用 UE 4.26 自动修复；修正版仍缺少 7 根 IK 辅助骨。该个人素材库不包含在应用包内。
- Nodachi 接触区间为记录信息，当前不执行 IK；武器显示为参考几何。其他武器规则和远程同步尚未完成。
- 在另一台电脑使用既有素材库时，应单独备份并迁移整个库目录；跨库共享的角色库也应单独备份。避免多个应用进程同时写同一个库。

内置 Epic 基准资产的来源和许可说明随包保留。分享应用或个人素材前，请先确认各素材的许可允许对应的使用和分发方式。
